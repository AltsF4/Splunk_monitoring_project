# Splunk_monitoring_project
This was my CSC431 Linux Administration project at Dakota State University. The goal was to create a functional log-monitoring network with two servers, three workstations, and a network device. 

This is my first project posted on GitHub, so I'm including enough information for someone to understand as they read through the files.
